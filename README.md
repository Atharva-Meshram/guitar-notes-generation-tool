This website is live at :- https://atharva-meshram.github.io/guitar-notes-generation-tool/

Using this website you can write guitar tab notes in Meshram notation format. 

You just need to enter tabs and it will automatically generate corresponding aplhabetical fret notes ["C","C#","D","D#","E","F","F#","G","G#","A","A#","B"].

These fret note are important when you try to play same note on different instruments (like piano and etc) or change the octave on guitar itself.
